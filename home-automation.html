Smart Home IoT
& Automation

A cloud-independent, highly customized home automation ecosystem built on Home Assistant and custom hardware.

Ecosystem Breakdown

I despise cloud dependency for my physical living space. Every light switch, thermostat, and sensor in this project communicates locally via Zigbee or MQTT, orchestrated by a highly customized Home Assistant core instance.

Beyond off-the-shelf smart plugs, I design and program my own microcontrollers to bridge gaps where commercial products fail or are too expensive.

Technical Highlights

Custom ESP32 Sensors

Programmed in C++ (ESPHome/Arduino), these multi-sensors track temperature, humidity, and mmWave human presence for hyper-accurate automation triggers.

Zigbee Mesh Network

Over 80+ nodes communicating via a dedicated Zigbee2MQTT coordinator, ensuring rapid response times without crowding the 2.4GHz WiFi band.

Local Voice Control

Utilizing Rhasspy and local wake-word detection to process voice commands entirely offline, protecting household privacy.

React Dashboards

Wall-mounted tablets running custom React frontends querying the Home Assistant WebSocket API for real-time control.
