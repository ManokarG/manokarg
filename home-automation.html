Hardware & Software Stack

Home Assistant Core

The Orchestrator

Running in a dedicated Docker container on the Proxmox cluster. It acts as the central brain, unifying dozens of disparate protocols (Zigbee, WiFi, Bluetooth). I utilize Node-RED addon for complex, visually mapped automation flows that handle state machines for HVAC and lighting.

Custom ESP32 Sensors

Hardware Engineering

Commercial sensors are often slow and limited. I designed custom PCBs housing ESP32 microcontrollers flashed with ESPHome (C++). These multi-sensors track temperature, humidity, lux, and utilize mmWave radar for hyper-accurate, sub-second human presence detection (ignoring pets).

Zigbee2MQTT

Mesh Networking

To avoid crowding the 2.4GHz WiFi band, all smart bulbs, door sensors, and switches communicate via Zigbee. A Sonoff USB coordinator passed through to a Docker container runs Zigbee2MQTT, translating device states into MQTT topics for lightning-fast, local-only communication.

Rhasspy Voice Assistant

Offline NLP processing

No Alexa, no Google Home. I built custom smart speakers using Raspberry Pi Zeros and ReSpeaker HATs. Audio is streamed to a central server running Rhasspy, which handles Wake Word detection (Porcupine), Speech-to-Text, and Intent Recognition entirely offline, ensuring absolute privacy.
