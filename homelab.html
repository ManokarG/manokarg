Autonomous AI
& GitOps Homelab

An enterprise-grade, highly available local cloud for self-hosting, AI experimentation, and autonomous agents.

Architecture Overview

The entire infrastructure spans multiple bare-metal Proxmox hypervisors and a cluster of ARM-based edge nodes (Raspberry Pis). It is designed with zero single points of failure in mind, utilizing distributed databases (PostgreSQL/Redis) and Tailscale for secure, encrypted mesh networking.

I treat this homelab exactly like a production environment. 100% of the state is stored in Git, deployed via Ansible, and monitored via Prometheus and Grafana.

Core Pillars

n8n Automation Engine

Asynchronous task execution and CI/CD pipelines managed by decentralized n8n workers.

Local LLMs

Running DeepSeek and Llama models via Ollama for entirely private, offline AI inference and RAG.

Zero-Trust Security

Traefik reverse proxy coupled with Authelia for strict OIDC/SSO authentication before granting service access.

Self-Healing

Custom Python scripts intercept Prometheus alerts to auto-restart frozen containers before notifying via Gotify.
