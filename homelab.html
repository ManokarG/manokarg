Core Infrastructure Stack

Proxmox VE Cluster

Hypervisor & Compute

The foundation of the environment. Multiple bare-metal nodes form a highly available cluster. Utilizing ZFS for resilient storage and automatic snapshots. Virtual Machines (VMs) run heavy Docker hosts, while lightweight services are deployed directly as unprivileged LXC containers to minimize overhead.

Ansible & GitOps

Infrastructure as Code

Infrastructure drift is eliminated. 100% of the homelab's state—from OS updates and Docker Compose deployments to network configurations—is defined in YAML. Pushing a commit to the local Git server automatically triggers an Ansible playbook. Secrets are aggressively protected using Ansible Vault.

Traefik & Authelia

Zero-Trust Security

All incoming traffic hits the Traefik reverse proxy, which dynamically discovers Docker services and provisions wildcard Let's Encrypt SSL certificates via DNS challenge. Access to sensitive dashboards is blocked at the edge by Authelia, enforcing strict OIDC Single Sign-On (SSO) and Multi-Factor Authentication (MFA).

Ollama & DeepSeek

Autonomous AI Agents

A dedicated GPU-passthrough VM runs Ollama, exposing a local OpenAI-compatible API. This powers open-source models (like Llama 3 and DeepSeek) for complete offline privacy. Integrated with LangGraph and AnythingLLM, these models process local documents via RAG and act as autonomous agents for coding tasks.

n8n Workflow Engine

Asynchronous Automation

Moving beyond simple cron jobs, a highly available n8n cluster handles complex automation logic. It manages backup verifications, AI agent pipelines, and webhook parsing. It runs in a distributed master/worker configuration, with dedicated workers running in isolated LXC sandboxes to safely execute AI-generated code.

Prometheus & Grafana

Monitoring & Self-Healing

A robust metrics pipeline utilizing Prometheus, node-exporters, and Loki for log aggregation, beautifully visualized in Grafana dashboards. The system is designed for self-healing: Alertmanager triggers custom Python scripts that automatically reboot failed containers via the Docker socket before sending a Gotify notification.
